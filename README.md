# Saptarshi Bagchi Portfolio

## Run locally

```bash
npm install
npm run dev
```

Build for production with `npm run build`.
## Google Analytics

The GA4 Google tag is configured directly in `index.html`.
Replace the Measurement ID there if you use a different GA4 property.
For Vercel, deploy normally; no environment variable is required.

## Where to edit what

| What | File |
| --- | --- |
| Personal content, links, education, skills, projects | `src/data.js` |
| Page section order | `src/App.jsx` |
| Section markup | `src/components/` |
| Colors, layout, global stylesheet | `src/index.css` |
